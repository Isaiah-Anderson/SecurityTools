# SecurityTools
Toolkit for Basic Security Tasks
===================================================================================

## Windows Enumeration Tool
A Python script that runs common Windows commands and prints the results
in labeled sections. Useful for quickly gathering basic information about
a Windows host.
===================================================================================

## Windows Log Parser
A Python script that pulls recent security events from the Windows
Security log and prints them in labeled sections. Useful for quickly
reviewing login activity and spotting suspicious events on a Windows host.
===================================================================================

### Requirements
- Windows
- Python 3
